# 赛后报告样例

> **中文** · [English](README.en.md)

每局打完会生成一份自包含的 HTML（无外部依赖，双击就能看）。这里放几份代表性的（只选样本，不是全部对局）：

> **格式说明**：`01`~`03` 由早期引擎（v97）生成，**不含**随机种子、成本归因、
> 10 列成交明细、逐笔借款这几块。`04` 是 v1.0.11 时期引擎生成的完整报告。
> **v1.0.12 起**，「关键指标」里多了「其中强制平仓」和「结算后持仓」两行；
> 这里保留的样本生成于该改动之前，因此看不到这两行。

## 01 · 唯一达成 · qwen3.8-flash · +106.38%

```
最终权益   2,063,829.17    目标 2,000,000    评级 A
盈亏      +1,063,829.17（+106.38%）
用时      15 分 45 秒
最大回撤  21.86%    夏普 2.29    14 笔    胜率 50%
```

**为什么能赢**：胜率只有 50%，但**盈亏比 3:1**。

转折点在 tick 121 —— 认赔 23 万（平掉 AURA 空单 −197,567、TIDE 空单 −32,547），同时反手开 LUMEN 多单 6000 手。之后 LUMEN 从 0.9604 涨到 1.0610（+20.57%），分三批平仓共 +109 万。

**敢砍，也敢加。**

## 05 · 穿仓示例 · Hunyuan-Hy-高-WorkBuddy · −114.62%

```
最终权益     146,241.22    目标 2,000,000    评级 D
盈亏      −1,146,241.22（−114.62%）
```

本金被打穿，是「方向判断 + 成本」双重失控的样子。看它主要是为了知道红色权益曲线长什么样：
跌到本金归零之后，报告会把这一段单独标「穿仓」。

## 06 · 成本归因完整示例 · MiniMax-M3.1-Flash · −68.71%

```
最终权益     312,943.21    目标 2,000,000    评级 D
盈亏        −687,056.79（−68.71%）
```

当前引擎生成、且**含「场外援助」章节**的完整样本（v1.0.6 起的报告才有这一段）。
成本归因的五个分项全部有数：这一局滑点成本占总亏损约 58%，是典型的「死在成本上」。
另注意「场外援助」是空章节——无头启动时观众席没人应答，那条求助 ticket 没人处理。

## 04 · 新格式完整示例 · 当前引擎生成

这份的意义不在盈亏，在于它包含**现在报告的全部区块**：随机种子与复现方式、
难度具体参数（跳空概率 / 流动性深度）、成本归因五段（毛盈亏 / 滑点 / 点差 /
手续费 / 隔夜利息）、10 列成交明细、逐笔借款与目标上浮、草稿纸、关键事件流。

## 02 · 典型失败 · WorkBuddy-Agent · −76.95%

```
最终权益     230,483.51    目标 2,000,000    评级 D
盈亏        −769,516.49（−76.95%）
```

这一局的操作记录和事件流都在报告里。它展示了这个游戏最常见的死法：

**不是方向判断错，是死在成本上。** 手续费 + 隔夜利息占了总亏损的相当一部分，而 45 分钟里反复进出会把成本堆到无法承受。

## 03 · 小幅亏损 · GLM-5.3-Flash · −9.10%

```
最终权益     909,030.39    目标 2,000,000    评级 D
盈亏         −90,969.61（−9.10%）
用时         38 分 51 秒
最大回撤     14.06%    夏普 −0.89    11 笔    胜率 36.4%
```

**「输得不多」也是一种输。** 评级只看到没到目标，不会因为「亏得少」就给高分。

## 怎么读这份报告

| 区块 | 看什么 |
|---|---|
| **权益曲线** | 绿色虚线是初始本金，金色是目标，红色是本金归零。跌破红线会被标「穿仓」 |
| **关键指标** | 黑天鹅频率 / 流动性枯竭程度 —— 这局的难度 |
| **借贷账目** | 借了多少、还了多少、利息多少、还款前后现金 |
| **成交明细** | 全部交易，不截断 |
| **事件流** | 全部事件，含跳空、流动性枯竭、政策事件 |
| **草稿纸** | AI 在局中写下的判断依据（人类玩家没有这个区块） |
