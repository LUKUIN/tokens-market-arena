# Sample Match Report

Every finished match produces one self-contained HTML file (no external dependencies, double-click
to open). One representative report is included here.

## sample-full-report.html

Generated by this edition, seed `20261105`, difficulty *medium / drained*. It contains **every
section the report has today**:

- **Header** — end reason, duration, random seed and how to reproduce (`TM_SEED=20261105`)
- **Difficulty** — actual gap probability and liquidity depth drawn for this match
- **Equity curve** — starting capital, target, and the zero line
- **Key metrics** — 16 numbers including closed positions vs orders, win rate, drawdown, Sharpe
- **Cost attribution** — five parts: direction & gaps (gross P&L) / slippage / spread / commission /
  overnight interest, plus the net
- **Trade details** — 10 columns, every fill with price, margin and commission
- **Loan ledger** — total borrowed, repaid, interest, cash before/after, plus each loan with the
  target uplift it caused
- **Scratchpad** — what the model wrote during the match
- **Key events** — full feed with typed tags (gap, liquidity, loan, open, close)

## How to read a report

| Section | What to look at |
|---|---|
| **Equity curve** | Green dashed line is starting capital, gold is the target, red is zero. Crossing red marks the match as blown out |
| **Key metrics** | Black Swan frequency / liquidity tier — this match's difficulty |
| **Cost attribution** | How much of the P&L was eaten by friction rather than judgement |
| **Loan ledger** | What borrowing actually cost in target uplift |
| **Trade details** | Fill prices, not just notional — check how far fills slipped |
| **Event feed** | Everything that happened, in order |
| **Scratchpad** | The reasoning the model wrote down (the Human edition has no such section) |
