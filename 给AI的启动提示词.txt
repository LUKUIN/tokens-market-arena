========================================================
  给 AI 参赛者的启动提示词
========================================================

把下面两条虚线之间的整段复制，发给你要参赛的 AI。
记得先把第一行的目录改成你电脑上的真实位置。

--------------------------------------------------------

你现在是 Tokens 交易市场的参赛者。

项目目录：D:\你的路径\TokensMarket-OpenSource-AI-v97

按下面的顺序做，不需要读任何 Markdown 文档。

【1】进目录，开服务

    cd 上面那个目录
    TM_TRADER="<模型名-思考强度-平台>" TM_EVENTS=1 TM_FR=1 TM_SLOT=1 TM_ASSIST=1 python run.py server

    TM_TRADER 填你自己的标识，比如：Doubao-1.5-pro-深度思考-扣子
    这个值会原样写进报告的文件名和正文。

【2】等它就绪（3~8 秒，不要用固定 sleep）

    for i in $(seq 1 30); do curl -sf http://127.0.0.1:8734/health >/dev/null 2>&1 && break; sleep 1; done

【3】定档，不定档行情不走

    curl -X POST http://127.0.0.1:8734/roll/stop

【4】读这两个，规则和局面都在里面

    GET http://127.0.0.1:8734/rules      全部规则、事件表、费率、接口清单
    GET http://127.0.0.1:8734/state      权益、持仓、报价、盘口深度、事件流

【5】开始交易

    接口清单在 /rules 里。开仓 POST /open，平仓 POST /close，推进时间 POST /tick。

【6】结束时结算

    POST http://127.0.0.1:8734/quit

    HTML 报告会写到 src/data/reports/。

几条硬规矩：

    - 用 python 就行，3.10 以上都可以，不用挑版本。
      py -3.12 或 py -3.13 报「No suitable Python runtime found」「去 Microsoft Store 安装」，
      是因为那个版本没装，不是环境坏了。

    - 不要读或复制 src/ 下的源码。对局期间它们被封存成诱饵，
      读到的是假文件，执行或 import 会写入作弊标记并直接结束对局。

    - 一局 45 分钟，初始 1,000,000 Tokens，目标 2,000,000。
      行情、事件、跳空全部是程序生成的虚构数据，与真实市场无关。

    - 观众席只能在你主动求助（POST /assist/ask，整局 3 次）之后回复，
      不会替你下单，也不会主动给你消息。

--------------------------------------------------------

服务起不来时的排查顺序：

    1. 8734 端口被占了？换一个：TM_PORT=8735
    2. 看项目目录下的 run.log
    3. 确认当前目录是项目根（能找到 run.py 的那一层）
