# 成本模型

这里列的是源码版基础成本。局内事件可以修改手续费、点差、保证金、市场深度和持仓费率。下文示例均固定输入，方便核算。

## 四层成本

| 成本 | 计算口径 |
|---|---|
| 手续费 | 每次成交名义价值的 0.02%，开仓和平仓均收。 |
| 点差 | 每次成交计入一半有效点差。基础点差为 AURA 0.060%、FROST 0.080%、AMBER 0.100%、TIDE 0.100%、LUMEN 0.070%、NEON 0.075%、ASH 0.110%。 |
| 滑点 | 加成与封顶前为 `K / (2 × L) × (after² − before²)`，`K = 0.0024`。名义敞口按账户总额，`L` 取该笔交易品种的当前深度。平仓按剩余敞口到平仓前敞口的区间计算。 |
| 持仓费（隔夜费） | 按成本时钟向当前持仓名义价值计提。每次基础利率为 AURA 0.0020%、FROST 0.0030%、AMBER 0.0040%、TIDE 0.0030%、LUMEN 0.0020%、NEON 0.0025%、ASH 0.0045%。 |

正常单边滑点率上限为 1.4%，深度枯竭时为 6%。按成本时钟计，最后 15 分钟 `K` 从 1.0 倍线性增至 1.5 倍。只有价格、深度和修正都固定、且滑点未封顶时，拆单走过同一敞口区间的滑点成本才相同。

## 往返成本示例

假设空仓开一笔 AURA 后按相同中间价立即平仓，基础点差 0.06%、市场深度固定。下表为近似计算，省略持仓费和成交价造成的微小手续费差异。

| 名义规模 | 深度 800 万 | 成本占初始本金 100 万 |
|---:|---:|---:|
| 100 万 | 1,300 | 0.13% |
| 300 万 | 5,700 | 0.57% |
| 500 万 | 12,500 | 1.25% |
| 1,000 万 | 40,000 | 4.00% |
| 2,000 万 | 140,000 | 14.00% |

以 1,000 万名义为例，其他条件相同，深度 3,200 万的估算是 17,500，1,600 万是 25,000，400 万是 70,000，200 万是 130,000。

**高名义行只用于比较成本。** 开仓检查要求扣掉本笔手续费后的净值覆盖 150% 的维持保证金。在基础维持保证金率 10%、初始本金 100 万时，起始名义敞口上限略低于 667 万，还要通过可用保证金校验，并考虑事件修正。

例如 500 万名义想赚 100 万，忽略成本需 20.0% 的有利变动；把往返成本固定在 12,500 时，近似需 20.25%。真实行情变动还会改变平仓名义和成交成本。

## 跳空、强平与结算

黑天鹅基础跳空幅度为 2%–12%，方向随机，叠加在普通价格变动上。跳空可能越过计划退出价。当前接口按即时模拟成交价成交，未提供挂止损单。跳空当步相关品种的点差放大三倍。流动性枯竭单独改变市场深度和滑点上限。

维持保证金 = 名义敞口 × 10% × 当前保证金倍数。保证金水平低于 100% 进入追缴，恢复到 100% 后解除，30 个行情步未恢复会强平；低于 50% 则立即强平。主动平仓、爆仓强平和局终清算采用相同成交与收费公式。局终自动清算不受常规平仓限制，并从现金里清偿贷款。若持仓、欠款或账本校验有异常，需看结算告警。

## 持仓费与贷款利息

持仓费按当前名义计提。贷款是单独的 0.01% 每次，按未还余额复利。100 万本金经历 540 次计提约变为 1,055,482；500 万名义按 0.003% 固定持仓费计提 540 次，成本示例为 81,000。

成本时钟按每 5 个对局秒折算，并受实际行情步数约束。持仓费、贷款利息和末期滑点都按这个口径。

复盘时看战报的成本归因。历史样本可能使用旧规则和不同市场路径，凭这些报告不能推断最优仓位或模型胜率。
