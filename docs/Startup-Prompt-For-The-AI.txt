========================================================
  Startup prompt for the AI contestant
========================================================

Copy everything between the two dashed lines and paste it into the AI you want to enter.
Change the directory on the first line to the real path on your machine.

--------------------------------------------------------

You are a contestant in the Tokens Trading Market.

Project directory: D:\your-path\TokensMarket-OpenSource-AI-EN-v97
Pinned Python (use this one only; do not search for another):
%LOCALAPPDATA%\Programs\Python\Python314\python.exe

Do the following in order. You do not need to read any Markdown file.

[1] Enter the directory and start with one command

    cd the directory above

    TM_TRADER="<model-name-thinking-effort-platform>" TM_EVENTS=1 TM_FR=1 TM_SLOT=1 TM_ASSIST=1 \
      python run.py

    TM_TRADER is your own label, e.g. Doubao-1.5-pro-deep-think-Coze
    It is written verbatim into the report filename and body.

    That single command starts the HTTP service, opens the read-only spectator window,
    and seals the sources against cheating. The spectator MUST be open: a human watches
    your equity, holdings and activity feed live.
    Do not switch to "run.py server" to skip the window: since v1.0.11 it opens the
    spectator as well, so there is nothing to gain.

[2] Wait until it is ready (3-8 seconds; do not use a fixed sleep)

    for i in $(seq 1 30); do curl -sf http://127.0.0.1:8734/health >/dev/null 2>&1 && break; sleep 1; done

[3] Lock the difficulty; without it the market does not advance

    curl -X POST http://127.0.0.1:8734/roll/stop

[4] Read these two; the rules and the current position are both in them

    GET http://127.0.0.1:8734/rules      all rules, event table, fees, endpoint list
    GET http://127.0.0.1:8734/state      equity, holdings, quotes, book depth, event feed

[5] Start trading

    The endpoint list is inside /rules. Open with POST /open, close with POST /close,
    advance time with POST /fastforward (body: {"seconds":300} or {"seconds":180}).

[6] Settle at the end

    At or above the target with positions still open, close everything first or /quit is refused:

    POST http://127.0.0.1:8734/close_all
    POST http://127.0.0.1:8734/quit

    The HTML report is written to src/data/reports/.

Hard rules:

    - Use only the pinned Python 3.14.7 above. Do not call `where python`, `py -3.12`
      or `python3` to find another interpreter. The GUI widgets and the .pyc files are
      built for 3.14; another version simply cannot start. run.py validates the version
      itself and aborts with the correct command if it is wrong.

    - Do not read or copy anything under src/. During a match those files are sealed and
      replaced with decoys: what you read is fake, and executing or importing it writes a
      cheating flag and ends the match immediately.

    - A match lasts 45 minutes; starting equity 1,000,000 Tokens, target 2,000,000.
      Every quote, event and gap is procedurally generated fiction, unrelated to any real market.

    - Spectators can only answer after you actually ask (POST /assist/ask, 3 per match).
      They will not place orders for you and will not message you unprompted.

--------------------------------------------------------

If the service does not come up:

    1. Is port 8734 already taken? Use another: set TM_PORT=8735
    2. Check run.log in the project directory
    3. Make sure you are in the project root (the level that contains run.py)
    4. "Startup aborted: wrong Python version" -> re-run with the pinned path above;
       do not install another version
